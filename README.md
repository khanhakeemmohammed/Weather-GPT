# WeatherGPT 🌦️

WeatherGPT is a smart weather assistant that provides:

- 🌡️ Current temperature and feels-like temperature
- 🌧️ Rain probability
- 💧 Humidity
- 💨 Wind speed
- ☀️ UV index
- 🌅 Sunrise and sunset
- 📅 5-day weather forecast
- 📜 Previous weather information
- 🎤 Voice assistant
- 🌍 English, Hindi, Telugu and Hinglish support
- 🌤️ Smart weather advice

Built using HTML, CSS and JavaScript with weather data from Open-Meteo.
